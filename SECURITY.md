# Security Policy

WOSP manages Google Workspace security and configuration for MSPs, so we hold ourselves to a high security bar. We take all reports seriously.

## Reporting a Vulnerability

If you discover a security vulnerability in any of our repositories or in the WOSP platform, please report it privately rather than opening a public issue.

- Email: info@wosp.app
- Include a description of the issue, steps to reproduce, and any relevant logs or screenshots.

We will acknowledge your report as soon as possible and work with you to understand and address the issue.
